# منصة نظر الشكاوى ضد المحامين

نظام متكامل لاستقبال ونظر الشكاوى والبلاغات ضد المحامين في المملكة العربية السعودية، وفق نظام المحاماة (م/38 لعام 1422هـ) واللائحة التنفيذية 1446هـ وقواعد السلوك المهني، مع إدماج ممكنات الذكاء الاصطناعي.

## المكدس التقني

| الطبقة | التقنية |
|--------|---------|
| الواجهة الأمامية | Next.js 14 (App Router) + Tailwind CSS (RTL عربي) |
| الخلفية | Python FastAPI + SQLAlchemy (async) |
| قاعدة البيانات | PostgreSQL 16 |
| الذكاء الاصطناعي | Anthropic Claude API |
| المصادقة | JWT + RBAC (8 أدوار) |
| التخزين | MinIO (S3-compatible) |
| المهام الخلفية | Celery + Redis |

## المستخدمون (8 أدوار)

| الدور | الوصف |
|-------|-------|
| مشتكي | يقدم الشكاوى ضد المحامين |
| محامي مشتكى عليه | يطلع على الشكوى ويرد عليها |
| محقق | يُجري التحقيق ويجمع الأدلة |
| مدعٍ عام | يعد لوائح الادعاء |
| عضو لجنة التأديب | يشارك في الجلسات |
| رئيس لجنة التأديب | يرأس الجلسات ويصدر القرارات |
| منفذ قرارات | ينفذ العقوبات التأديبية |
| مشرف/مدير | إدارة كاملة للنظام |

## ميزات الذكاء الاصطناعي

- **تصنيف الشكاوى تلقائياً** - تحديد نوع المخالفة والمادة النظامية والخطورة
- **المساعد القانوني للمشتكين** - chatbot بث مباشر يساعد في صياغة الشكوى
- **تحليل مخاطر المحامي** - درجة مخاطر 0-100 مع تحليل الأنماط
- **اقتراح العقوبات التأديبية** - مع الظروف المشددة والمخففة
- **مولّد أسئلة التحقيق** - للمحققين
- **مساعد صياغة لوائح الادعاء** - للمدعين العامين
- **مساعد صياغة القرارات التأديبية** - لرؤساء اللجان
- **مراجعة الاتساق النظامي** - فحص الوثائق مقابل الأنظمة المعتمدة
- **رصد المخالفات الليلي** - Celery Beat يعمل كل 24 ساعة

## الإعداد والتشغيل

### 1. نسخ المتغيرات البيئية
```bash
cp backend/.env.example backend/.env
# عدّل backend/.env وأضف ANTHROPIC_API_KEY
```

### 2. تشغيل Docker Compose
```bash
docker-compose up -d
```

### 3. الوصول للمنصة
- الواجهة الأمامية: http://localhost:3000
- توثيق API: http://localhost:8000/api/docs

## هيكل المشروع

```
Ras/
├── backend/          # FastAPI application
│   └── app/
│       ├── models/   # SQLAlchemy ORM models
│       ├── routers/  # API endpoints
│       ├── services/ # Business logic + state machine
│       ├── ai/       # Claude API integrations
│       │   ├── analyzers/     # AI analysis engines
│       │   └── legal_knowledge/  # Saudi legal framework data
│       └── tasks/    # Celery background tasks
└── frontend/         # Next.js application
    └── src/app/
        ├── auth/          # Login & Register
        └── dashboard/     # Protected pages (RTL Arabic UI)
```
